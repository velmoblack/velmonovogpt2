# Velmo Black — vídeo móvel

Substitua somente `index.html` na raiz do repositório. O vídeo flutuante pode ser arrastado pelo cabeçalho “Arraste o vídeo”. Ao clicar no X, ele fica oculto até a página ser recarregada; uma nova visita também mostra o vídeo normalmente. O botão “Ouvir vídeo” mantém a reprodução com áudio após clique.
